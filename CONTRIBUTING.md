# Contributing

Mahler is a tool for creative technologists and developers on limited token budgets. If you have ideas, bug reports, or improvements, please contribute.

## How to Contribute

1. **Found a bug?** [Open an issue](https://github.com/sinaida-space/mahler-the-orchestrator/issues)
2. **Have a feature idea?** [Open a discussion](https://github.com/sinaida-space/mahler-the-orchestrator/discussions)
3. **Want to improve the docs?** Fork, edit, and submit a PR

## Improving Mahler

Areas where contributions help most:

- **Routing refinements** — Adding new domains or refining model assignments
- **Documentation** — Better examples, troubleshooting, use cases
- **Interrogation templates** — More specific question sets for different project types
- **Integration patterns** — How Mahler works with your specific tool (TouchDesigner, etc.)

## Code of Conduct

Be kind. This is a tool for humans working with AI. Treat others as you'd want to be treated.
