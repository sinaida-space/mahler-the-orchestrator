# Quick Start

## 30 seconds

```bash
git clone https://github.com/sinaida-space/mahler-the-orchestrator.git
cp -r mahler-the-orchestrator ~/.claude/skills/mahler
```

Restart Claude Code. Type `/mahler`. Done.

## 5 minutes

1. Read [README.md](README.md) — understand what Mahler does
2. Look at [docs/INSTALLATION.md](docs/INSTALLATION.md) — install it properly
3. Check [examples/EXAMPLE-SHADER-WEB-APP.md](examples/EXAMPLE-SHADER-WEB-APP.md) — see how it works on a real project

## 30 minutes

- Read [docs/ROUTING.md](docs/ROUTING.md) — understand model assignments
- Read [docs/INTERROGATION.md](docs/INTERROGATION.md) — learn the interrogation protocol
- Try `/mahler` on your own project
